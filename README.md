# UniPrep 2027 · 스스로 준비하는 대학입시

고등학생이 스스로 대학 입학전형을 준비할 수 있도록, 서울특별시교육청교육연구정보원 「쎈(SEN)진학 2027 대입 고3 학년 초 대입전형의 이해와 대비」(2026. 2. 2.) 자료집을 바탕으로 만든 인터랙티브 사이트입니다.

- 사이트: https://yalli2.github.io/university/
- 메뉴: 홈 · 전형 가이드 · 나의 체크리스트 · 대입 일정 · 대학별 전형 · 지원 플래너 · 2027 한눈에
- **전형 가이드**: 학생부교과·학생부종합·논술·수시 공통·정시·음악·연극영화·미술·체육·전문대·사회통합(기회균형) — 핵심 포인트, 평가 방법, 2027 변경사항, 자료 표, 준비 팁, 주의사항
- **나의 체크리스트**: 학년(고1~고3)과 목표 전형에 맞춰 단계별(고1 → 정시 원서접수) 할 일을 체크, 진행률 저장(브라우저 localStorage)
- **대입 일정**: 수시·수능·정시·추가모집 일정과 D-day, 월별 달력
- **대학별 전형**: 4년제 대학 전형계획(수시 전형·인원·전형방법·수능최저, 정시 군별 인원·반영비율, 영어 반영) 검색·필터, ★ 관심 대학
- **지원 플래너**: 수시 6장 + 정시 가·나·다군 조합 짜기, 수능최저 비교, 인쇄
- 디자인: worldlanguage 사이트와 같은 형식

## 데이터
- `data/base.json` — 일정·모집인원·변경사항 등 개요
- `data/susi.json`, `data/jungsi.json`, `data/etc.json` — 전형 가이드
- `data/univ1.json`, `data/univ2.json` — 대학별 전형계획
- `tools/build.py` — 위 자료를 합쳐 `data.js` 생성: `python3 tools/build.py data data.js`

대학입학전형 계획과 전형요강은 대학 사정에 의해 바뀔 수 있습니다. 반드시 대학이 발표하는 최종 모집요강을 확인하세요.
